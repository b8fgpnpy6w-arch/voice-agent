# Voice Agent

An open-source, self-hosted voice assistant powered by Claude.

> 🚧 Early stage – work in progress.

## Idea

Today's voice assistants are closed and controlled by big cloud providers. Voice Agent lets anyone run their own private, capable voice assistant at home.

## Planned features

- **Home server** – runs the agent locally on your own hardware
- **Mac & iOS apps** – talk to your agent from anywhere
- **Voice calls** – call your agent like a person
- **Car mode** – starts automatically when you get in the car
- **DIY voice devices** – small speakers/mics for every room
